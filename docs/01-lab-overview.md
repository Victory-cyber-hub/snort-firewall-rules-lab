# 01 — Lab Overview

## Purpose

This lab introduces the relationship between an IDS and firewall controls in a controlled virtual environment.

## Objectives

- Prepare the virtual environment.
- Work with firewall and IDS logs.
- Generate and observe test traffic.
- Capture network evidence.
- Tune a firewall rule based on an IDS finding.
- Terminate and clear the Mininet environment.

## Lab Components

- CyberOps Workstation
- Mininet
- R1
- H5
- H10
- Snort
- iptables
- tcpdump
